# 변경 이력

공개 가능한 결과 중심 변경 요약이다. 항목은 일자 단위이며 최신 항목을 위에 둔다.

## 2026-08-11 — 로컬 환경 경계와 빌드 산출물 격리

### Fixed

- 로컬 서버 전용 환경 값은 git-ignored `.dev.vars`로 분리하고, Next.js/OpenNext가 읽는 `.env`에는 공개 URL만 둘 수 있게 했다.
- 개발 서버와 표준 프로덕션 빌드는 각각 `.next`, `.next-build`를 사용하도록 분리해, 동시에 실행해도 산출물을 덮어쓰지 않게 했다. OpenNext용 Cloudflare build는 호환성을 위해 `.next`를 명시적으로 사용한다.
- `npm run start`는 표준 빌드 산출물을 `3004`에서 실행하며, 빌드 후 개발용 route type을 자동으로 갱신한다.

## 2026-08-11 — 로컬 개발 서버 포트 계약

### Changed

- Node와 Docker 개발 서버의 고정 포트를 `3004`로 통일했다.
- 포트 값이 달라지면 실패하는 설정 계약 테스트를 추가했다.

## 2026-08-11 — Lumo 시그니처 모션과 타이포그래피 복원

### Changed

- 각 공개 화면의 cipher heading과 stagger reveal, blur 기반 route transition을 복원했다.
- ambient scene과 cursor glow를 공개 route 전반에서 유지한다.
- reduced-motion을 선택한 환경에서는 모션을 생략하고 제목과 본문을 즉시 표시한다.

## 2026-08-11 — 공개 route ambient 배경 범위 확장

### Changed

- Home에만 표시하던 선택적 ambient 배경을 모든 공개 route에서 유지한다.
- reduced-motion, 절전·저성능 환경, WebGL 오류에서는 기존 static fallback을 계속 사용한다.

## 2026-08-11 — 공개 콘텐츠와 검색 메타데이터 전달 정비

### Changed

- 공개 화면은 요청 언어의 필요한 콘텐츠만 서버에서 전달하고, 상호작용이 필요한 화면 부분만 브라우저에서 동작하도록 정리했다.
- Home, 소개, 음악, 공연, Archive, 문의, 링크의 핵심 본문과 링크가 첫 HTML에 포함된다.
- 각 공개 경로에 canonical, Open Graph, Twitter 메타데이터를 추가하고, 존재하지 않는 공연·Archive 상세 주소는 실제 404로 처리한다.
- 관리자 편집용 콘텐츠 로딩은 관리자 영역으로 한정해 공개 화면에 영향을 주지 않도록 분리했다.
- 공개 콘텐츠를 읽을 수 없을 때 빈 화면으로 보이지 않도록 재시도와 홈 복귀 action을 제공한다.

## 2026-08-11 — 공개 화면 가독성과 모션 경계

### Changed

- 공개 본문과 메타 글자 크기, 보조 텍스트 대비, 주요 action의 최소 터치 영역을 정리했다.
- 모든 공개 route의 cipher heading reveal을 즉시 표시로 전환하고 reduced-motion 환경에서 전환·로딩 animation을 최소화한다.
- 3D와 cursor glow를 Home desktop의 선택적 ambient layer로 한정하고, 절전·저성능·WebGL 오류 환경에는 static fallback을 사용한다.
- native scrollbar를 복원하고 사용자 운영체제의 스크롤 접근성 설정을 존중한다.

## 2026-08-11 — 공개 탐색 접근성

### Changed

- 본문 바로가기, 현재 route 표기, route 전환 뒤 본문 focus, EN/KO 문서 언어 동기화를 추가했다.
- 모바일 navigation을 닫힌 상태에서 tab 순서에 남지 않는 focus 경계로 바꾸고 Escape, backdrop, desktop breakpoint 뒤 trigger focus를 복원한다.
- Archive 목록과 상세를 semantic link·article·이름 있는 이전/다음 탐색으로 정리하고 장식 아이콘을 보조 기술에서 제외했다.

## 2026-08-11 — 관리자 편집 안전성과 접근성

### Changed

- 입력·텍스트영역·선택 필드를 공통 label, id, name 계약으로 정리하고 라디오 선택은 브라우저 기본 키보드 동작을 사용하도록 개선했다.
- 저장되지 않은 콘텐츠가 있으면 언어 전환, 관리자 메뉴 이동, 사이트 이탈과 새로고침 전에 확인하도록 보강했다.
- 저장 성공·실패 상태를 화면 읽기 도구에 알리고, 저장 실패 시 오류 안내로 포커스를 이동하도록 개선했다.
- 콘텐츠 삭제를 확인 대화상자로 통일하고 Escape 취소와 이전 trigger 포커스 복원을 제공한다.

## 2026-08-11 — 관리자 저장 결과 신뢰성

### Fixed

- 관리자 콘텐츠 저장에서 HTTP·네트워크·응답 형식 오류와 실패 응답을 모두 오류로 처리하도록 정리했다.
- Home, About, Music, Events, Contact, Link, Archive에서 일부 저장에 실패하면 성공 알림 대신 실패 영역과 재시도 방법을 표시하도록 개선했다.
- 갤러리·이벤트 포스터 업로드가 multipart 요청 형식을 유지하면서 실패 결과를 처리하도록 보강했다.

## Unreleased

### Security

- 공개 콘텐츠 응답에서 외부 이벤트 연동 자격정보 설정을 분리하고 모든 응답을 저장 금지 처리했다.
- 관리자 설정 조회는 자격정보 저장 여부만 반환하고 실제 키 값은 브라우저에 노출하지 않도록 변경했다.
- 과거 공개 콘텐츠 브라우저 캐시를 정확한 키 범위에서 제거하도록 정리했다.
- Worker 빌드에 허용되지 않은 환경 변수가 포함되지 않도록 소스와 산출물 검증 단계를 추가했다.

### Docs

- 공개 문서와 내부 작업 문서의 분리 기준을 적용했다.
- 변경 이력과 트러블슈팅을 일자 단위 항목으로 정리했다.
- 저장소 진입점 README와 문서별 검증 절차를 보강했다.
