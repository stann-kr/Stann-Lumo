# 변경 이력

공개 가능한 결과 중심 변경 요약이다. 항목은 일자 단위이며 최신 항목을 위에 둔다.

## Unreleased

### Security

- 공개 콘텐츠 응답에서 외부 이벤트 연동 자격정보 설정을 분리하고 모든 응답을 저장 금지 처리했다.
- 과거 공개 콘텐츠 브라우저 캐시를 정확한 키 범위에서 제거하도록 정리했다.
- Worker 빌드에 허용되지 않은 환경 변수가 포함되지 않도록 소스와 산출물 검증 단계를 추가했다.

### Docs

- 공개 문서와 내부 작업 문서의 분리 기준을 적용했다.
- 변경 이력과 트러블슈팅을 일자 단위 항목으로 정리했다.
- 저장소 진입점 README와 문서별 검증 절차를 보강했다.

## 2026-06-25 — Dockerfile 플랫폼 고정 해제

### Changed

- Dockerfile의 base image에서 `--platform=linux/arm64` 지정을 제거했다. 로컬 Compose의 `linux/arm64` build target은 유지했다.

## 2026-06-16 — 토큰 드리프트 가드

### Added

- 빌드 전 단계에서 공통 디자인 토큰의 해시를 검증하는 드리프트 가드를 도입했다.

## 2026-06-13 — 사후 정비

### Changed

## 2026-06-12 — STANN OS 통일

### Added

- 세 사이트가 공유하는 디자인 토큰 정본을 도입했다.
- 사이트 간 이동을 위한 SIGNAL_NET 링크와 시스템 식별자 표기를 추가했다.

### Changed

- 세 사이트에서 변하지 않아야 할 글루 요소(셀렉션, 포커스, 라벨 문법)를 정렬했다.

## 2026-03-24 — UI 일관성과 어드민 연결성 개선

### Changed

### Fixed

## 2026-03-23 — 3D 씬 개선과 디자인 시스템 점검

### Changed

- 홈 화면의 3D 씬과 레이아웃을 개편했다.
- 디자인 시스템을 전면 점검하고 토큰 사용을 정리했다.

### Fixed

- 표시·상태 관련 버그를 정리했다.

## 2026-03-20 — 갤러리·이벤트 연결과 어드민 편집 기능

### Added

- 갤러리와 이벤트를 연결하는 흐름을 완성하고 갤러리 상세 페이지를 추가했다.
- 링크 관리에 아이콘 선택 UI를 추가했다.

### Fixed

- iOS 모바일 표시 문제와 갤러리 힌트 라벨을 수정했다.
- 갤러리와 이벤트 연결 누락, 연락처 섹션 정리 등 크리티컬 버그를 해결했다.
- lint 훅 규칙에 걸리던 코드 패턴을 근본적으로 수정했다.
